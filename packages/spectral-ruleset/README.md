# @ligeirinho/spectral-ruleset

Spectral ruleset for the [REST API](../../rules/rest-api.md) and [scale](../../rules/scale.md) rules, checked on the
OpenAPI document generated by `@nestjs/swagger`.

```yaml
# .spectral.yaml
extends:
  - '@ligeirinho/spectral-ruleset'
```

```sh
spectral lint openapi.json --fail-severity=warn   # @stoplight/spectral-cli 6.17.0
```

## Rules (all `error`)

| Rule | Fails on | Source |
|---|---|---|
| `ligeirinho-kebab-case-paths` | `/ticketTypes`, `/tasks/{task_id}` (segments kebab-case, parameters `{camelCase}`) | rest-api.md |
| `ligeirinho-no-verbs-in-paths` | a segment, or its first word, that is approve, cancel, create, delete, remove, send, verify, login, logout, update, get, fetch, list, add, edit, activate, deactivate, reset, confirm, submit | rest-api.md |
| `ligeirinho-no-caller-names-in-paths` | a segment that is admin, backoffice, back-office, internal, public, app, web, mobile, frontend, client | rest-api.md |
| `ligeirinho-no-secrets-in-urls` | a path or query parameter named code, password, secret, token, key, apikey, api-key, access_token, refresh_token (case, `-` and `_` ignored), or ending in Password / Secret / Token | rest-api.md |
| `ligeirinho-created-location` | a collection `POST` answering 201 without a `Location` header, when `GET {collection}/{id}` exists | rest-api.md |
| `ligeirinho-create-responds-201` | a collection `POST` answering 200 and none of 201 / 202 / 204 | rest-api.md |
| `ligeirinho-paginated-collections` | a collection `GET` returning an array (or an object with an array `items` / `data`) without `cursor` or `page`, and `limit`, query parameters | scale.md |
| `ligeirinho-problem-details-errors` | a 4xx / 5xx response whose body is missing or not only `application/problem+json` | rest-api.md |

A collection path is one that doesn't end in a parameter (`/tasks`, `/tasks/{taskId}/comments`).

Exceptions, skipped by every rule: `/oauth2`, `/health`, `/me`, `/.well-known` and anything under them (`/members`
is still checked). A new exception is a project override in `.spectral.yaml` (`rules: { <rule>: off }` or
`overrides`) with a comment giving the reason, mirrored in `.ligeirinho.yml`.
